# App directory and product pages

Status: draft plan. Depends on the shared layout and visual foundation; enlarged
screenshots depend on the shared viewer in the resume plan.

## Milestones

1. [ ] **App data.** Define a small typed list with a stable identifier, name, tagline,
       icon, description, and labeled App Store links. Keep content in code.
2. [ ] **Directory.** Render tiles with icon, name, tagline, and an App Store button.
       Give detail-page and store links distinct, accessible targets.
3. [ ] **App detail route.** Add each app's title, icon, introduction, features, and
       store links. Use the shared metadata layout and real app-specific copy.
4. [ ] **Screenshots.** Add responsive screenshot galleries and descriptive alternative
       text. Connect them to the shared viewer for enlargement and previous/next.
5. [ ] **Behind the app.** Support an optional section for engineering/design stories
       without forcing every app to have one.
6. [ ] **Launch apps.** Populate the agreed selection with real icons, store URLs,
       descriptions, and screenshots. Keep incomplete apps out of public navigation.

Inputs deferred to content work: the initial app list, actual store-link grouping,
screenshots, and any required product-specific support/privacy destinations.
Avoid live App Store API dependencies; this is a curated directory.
